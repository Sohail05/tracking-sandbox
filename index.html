How to verify events reached Meta

  1. Install the Meta Pixel Helper Chrome extension; it lists every event this page fires.
  2. In Events Manager, open your dataset, go to Test events, enter this page's URL and click "Open website". Events appear there live within seconds.
  3. The network ✓ badge in the log means the browser actually sent the request to facebook.com. If you never see it, an ad blocker or privacy setting is stopping the pixel.
  4. If Events Manager has traffic permissions (an allow list) turned on, add your github.io domain or events will be rejected.
